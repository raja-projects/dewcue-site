How to make a reminder from a web page or selected text

Save a page link or highlighted passage with a reminder, understand what stays local, and leave enough context to act later.

DewCue guides·3 min read·Documentation reviewed 18 October 2026

The useful answer

Use DewCue’s toolbar or right-click capture action to keep a page title, web address, and any selected text. Give the reminder a clear next action, then check its saved date and time. The captured page copy stays on the computer where you saved it.

Choose the page or passage you need

Start with the page you actually want to revisit. If one paragraph contains the useful detail, select that text before using the DewCue capture action. For example, you could keep a short passage from an article that you want to discuss at your next meeting.

Capture is something you choose. Merely visiting a website or seeing an on-page reminder card does not capture that page. The toolbar and right-click actions save the title, address, and selected text because you asked them to.

Leave your future self a clear next action

A link tells you where to go; a useful reminder also tells you why. “Review this delivery option before ordering” gives more direction than “Check website.” Keep your wording short enough to recognize when the reminder appears.

  1. Choose the relevant page or highlight the passage you want to keep.
  2. Start the DewCue toolbar or right-click capture action.
  3. Check the saved title, address, and selected text.
  4. Choose the task and timing, then verify the saved schedule.

Know what the capture keeps

The documented capture is a title, address, and selected text, not a complete offline archive of the website. Keep enough context to understand the task, and check the original page again before acting on information that may have changed.

Captured page information stays on that computer. Although reminders can sync through Chrome, do not assume that the local page copy transfers with them. Keep the original computer available if you need that saved context during a move.

Leave a sticky note on the page itself

Sometimes the page is the reminder. Pin a sticky note to any page and it reappears when you come back to that page. When the note becomes a task, turn it into a reminder in one tap.

Sticky notes use the optional all-sites permission you turn on yourself. Free includes 10 sticky notes, and Premium makes them unlimited.

Return to the page and decide what happens next

When the reminder is due, review the saved context and return to the page. Mark the task done when you finish it, snooze it when you need more time, or reschedule it if it still needs attention.

For something important, try a small reminder first so you know how your chosen alert behaves. The browser notification guide explains how to check on-page cards and system notifications.

A few related questions

Can I save a web page to revisit with a reminder?
Yes. When you choose the DewCue toolbar or right-click capture action, DewCue can save the page title, web address, and any selected text. Give the reminder a clear action and check its saved date and time. The captured page copy stays on the computer where you saved it.
Save a page with useful context
Can I turn highlighted text into a reminder?
Yes. Select the text you want to keep and use DewCue’s toolbar or right-click capture action. DewCue saves the selected text with the page title and address because you requested the capture. Check that the saved text contains enough context to understand the task later.
Use selected text in a reminder
Can I leave a sticky note on a web page?
Yes. Pin a note to any page and it reappears when you return to that page. Tap once to turn the note into a reminder. Free includes 10 sticky notes; Premium makes them unlimited. Sticky notes use the optional all-sites permission you turn on yourself.
Make reminders from web pages
Does capturing a page save a complete offline copy of the website?
The documented capture saves a page title, web address, and selected text. It should not be treated as a full-page archive. Keep enough context in the reminder to recognize the task, and check the original page when you return to it.
Understand what a page capture keeps
Will captured page text appear on my other computer?
The saved copy of a page title, address, and selected text stays on the computer where you captured it. Reminder syncing is a separate part of DewCue. Do not assume that a reminder appearing on another computer means the locally captured page information has transferred too.
Check what moves between computers
Does DewCue read or upload the pages I visit?
DewCue does not upload pages or collect browsing history. On-page cards, the ribbon, and page sticky notes use an optional permission for all sites that you turn on yourself; showing a card or the ribbon does not read the page. A page title, URL, or highlighted text is saved only when you capture it through the toolbar or right-click action, and a sticky note is kept on your computer with the page it belongs to.
